# Sicherheit

Bitte veröffentliche vermutete Sicherheitslücken nicht als öffentliche Issue.

Nutze stattdessen GitHub Private Vulnerability Reporting im Repository. Falls
diese Funktion nicht verfügbar ist, eröffne eine Issue ohne technische Details
und bitte die Maintainer um einen privaten Kontaktkanal.

Gib an:

- betroffene Version oder Commit
- nachvollziehbare Auswirkung
- minimale Reproduktionsschritte
- mögliche Abhilfe, falls bekannt

Veröffentliche keine Zugangsdaten, personenbezogenen Daten oder
Kundendokumente.
